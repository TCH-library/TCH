## 📥 How to Download

> ⚠️ **Follow these steps carefully. The process only needs to be done once per game session.**

### **Step 1: Enable Cheats and Plugins**
1. Open **PPSSPP**.
2. Go to **Settings → System**.
3. Enable the **Cheats** and **Plugins** options.
4. PPSSPP will create two folders inside the PSP directory:
   - `cheats`
   - `plugins`

### **Step 2: Download the Required Files**
1. Download the character code from our **[Website](https://your-site-link.com)**.
2. Download the required plugin.
3. Put the character's cheat/code file inside the `PSP/cheats/` folder.
4. Put the plugin files inside the `PSP/plugins/` folder.

### **Step 3: Start the Game**
1. Launch the game.
2. If you get a **black screen** or the game doesn't start properly:
   - Go back to the PPSSPP menu.
   - Open **Cheats** → Select **Disable All**.
   - Return to the game and make sure it starts normally.

### **Step 4: Select the Character**
After the game loads successfully:
1. Enter any battle mode: **Practice**, **Arcade**, **Story**, or **Ghost**.
2. Select the character for which you downloaded the code.
3. Start the battle.

### **Step 5: Enable the Codes**
1. Go back to the PPSSPP menu → Open **Cheats**.
2. Enable the codes you want to use.
   - For example: **Rage during Battle**, if available.
   - Other codes are optional and depend on what you want to use.
3. In the Cheat Menu, find **Refresh Rate**.
4. Set Refresh Rate to **16**.

> ⚠️ **IMPORTANT:** Setting the Refresh Rate to 16 is an **essential part** of the process.

### **Step 6: Return to the Game**
1. Go back to the game after enabling the codes.
2. The game may temporarily become **very laggy or slow**.
3. **Don't worry** — this is part of the process.

### **Step 7: Disable the Master/M Code**
1. Go back to the PPSSPP menu again.
2. Open **Cheats**.
3. Disable the **Master Code / M Code**.
4. Return to the game.

### **Step 8: Enjoy! 🎉**
